# 🧠 Data Science Projects – Excelr

This repository contains my completed assignments for the Data Science course conducted by Pragati AI. All work was developed in Google Colab and covers a wide range of machine learning and statistical techniques.

## 📁 Contents

### 📊 Exploratory & Statistical Analysis
- `EDA1.ipynb`, `EDA2.ipynb` – Exploratory Data Analysis
- `Basic_Stats_1.ipynb`, `Basic_Stats_2.ipynb` – Descriptive statistics
- `HypothesisTesting.ipynb` – Hypothesis testing methods

### 🤖 Machine Learning Models
- `LOGISTIC REGRESSION.ipynb` – Classification with Streamlit deployment
- `Decision_Tree.ipynb`, `Random_Forest.ipynb`, `KNN.ipynb`, `SVM.ipynb` – Supervised learning
- `CLUSTERING.ipynb` – Unsupervised learning
- `MLR.ipynb` – Multiple Linear Regression
- `NEURAL_NETWORKS.ipynb` – Deep learning basics
- `XGBM_&_LGBM.ipynb` – Gradient boosting models

### 📈 Specialized Techniques
- `PCA.ipynb` – Dimensionality reduction
- `Navie_Bayes_and_Text_Mining.ipynb` – Text classification
- `RECOMMENDATION SYSTEM.ipynb` – Collaborative filtering
- `Timeseries.ipynb` – Time series forecasting
- `ASSOCIATION RULES.ipynb` – Apriori algorithm for rule mining

### 🧪 Programming Foundations
- `PythonProgrammingAssignment.ipynb` – Core Python exercises
